Section A – Basic Level
Q1. Which package contains the Stream API?
A. java.lang.stream
B. java.util.stream
C. java.stream
D. java.io.stream
Correct Answer: B
Explanation: Stream API classes and interfaces are available in java.util.stream.

Q2. Which method is used to convert a Collection into a stream?
A. toStream()
B. asStream()
C. stream()
D. getStream()
Correct Answer: C
Explanation: Collection.stream() returns a sequential stream.

Q3. Which of the following is a terminal operation?
A. map()
B. filter()
C. sorted()
D. collect()
Correct Answer: D
Explanation: Terminal operations trigger stream processing and produce a result.

Q4. Streams in Java are:
A. Reusable
B. Mutable
C. Lazy
D. Synchronized
Correct Answer: C
Explanation: Stream operations are evaluated lazily until a terminal operation is invoked.

Q5. What is the return type of filter()?
A. List<T>
B. Set<T>
C. Stream<T>
D. Optional<T>
Correct Answer: C
